Protocols and routes

The glossary already has the two words. A protocol is the wire format of one request and its response. A route is a protocol bound to one provider's endpoint and authentication. Ollama and a llama.cpp server share a protocol and have different routes. OpenCode makes the same split. Its Protocol interface is documented as owning "what does this API look like" and not "which URL, which headers, or which auth scheme" (route/protocol.ts), and the whole OpenAI-compatible route is 24 lines that reuse the OpenAI Chat protocol (protocols/openai-compatible-chat.ts).

A provider that speaks a protocol the agent already has is one more row in this table. A provider with a new wire format needs a new protocol first. In the agent a protocol has three members: the path it posts to, a body function that turns the conversation into a request body, and a decode function that turns the response into a reply. Those functions work on the agent's own types, which come next.

The agent's own types

The loop needs a vocabulary that belongs to no provider. A message has a role and a list of content parts. A part is text, a tool call or a tool result:

Source: packages/ai/src/schema/messages.ts. OpenCode's result has two more variants, json and content, for structured and rich tool output. The agent's tools only return text or fail, so it keeps text and error.

Each protocol maps those shapes to its own:

Five decisions in these types

1. An error is a kind of result

Part 3 returned { content, isError }. Here the failure is part of the result's type, and each protocol writes it its own way: as text on OpenAI, as a flag on Anthropic. OpenCode's Anthropic encoder does the equivalent with is_error: part.result.type === "error" ? true : undefined (anthropic-messages.ts).

2. One tool message holds a step's results

The loop collects the results of every tool call in a step and pushes them as one message with the role tool. The OpenAI encoder splits it into one message per result, and the Anthropic encoder wraps it in a user message. This is the "every call needs its own result" rule from Part 3, expressed once instead of in two loops.

3. A reply says why it ended

decode returns { message, finish }, where finish is "tool-calls", "stop" or "refusal". The loop continues only on "tool-calls". The OpenAI decoder bases this on whether the message contains tool calls, not on the server's finish_reason, which is the check Part 3 used. The Anthropic decoder keeps the refusal check from Part 1.

4. native keeps what the types cannot hold

Claude's replies can contain thinking blocks. They are neither text nor tool calls in the agent's types, and they have to be sent back unchanged with the tool results. The assistant message gets an optional native field. The Anthropic decoder stores the original content array there and the Anthropic encoder sends it back. The loop never reads it. OpenCode models thinking as a reasoning part that carries the signature and rebuilds the thinking block when it encodes (anthropic-messages.ts). A reasoning part is worth adding once something displays or compacts reasoning, so the agent keeps the raw content for now.

5. Malformed arguments keep their raw text

On the OpenAI protocol arguments is a string, and JSON.parse can fail on a small model's output. The decoder then keeps the raw string as the call's input. runTool treats a string input as "not valid JSON" and returns the same instructive error as in Part 3, and the encoder sends the raw text back unchanged. A string that is valid JSON, such as "abc", gets the same message, which is slightly less precise and still tells the model to send an object.

runTool changes in two ways. It takes a tool call part instead of a name and a raw string, and it returns a tool result part instead of { content, isError }. Replace everything from type ToolResult down to the end of runTool (the line before // The OpenAI protocol's wrapping of a tool) with: 

// Never throws: every failure becomes a tool result the model can read.
const runTool = async (call: ToolCallPart): Promise<ToolResultPart> => {
  const done = (result: ToolResultValue): ToolResultPart => ({ type: "tool-result", id: call.id, name: call.name, result })

  try {
    const tool = tools.find((tool) => tool.name === call.name)
    if (!tool) throw new Error(`Unknown tool: ${call.name}. Available tools: ${tools.map((tool) => tool.name).join(", ")}`)

    // A string input is arguments that were not valid JSON; the protocol keeps the raw text.
    if (typeof call.input === "string") throw new Error(`The arguments are not valid JSON: ${call.input}`)

    if (tool.confirm) {
      const answer = await rl.question(`Allow: ${tool.confirm(call.input)}? [y/N] `)
      if (answer.trim().toLowerCase() !== "y") throw new Error("User declined this action. Ask what they would like instead.")
    }
    return done({ type: "text", value: await tool.execute(call.input) })
  } catch (error) {
    return done({ type: "error", value: error instanceof Error ? error.message : String(error) })
  }
}

done builds the result part, so the success and failure paths cannot disagree about the id and name. A result is a text on success and an error on every failure: an unknown tool, a string input, an input that fails field, a declined confirmation and an executor that throws.

Step 2: Move the OpenAI wire format into a protocol

Replace everything from the comment // The OpenAI protocol's wrapping of a tool to the end of the file with the six blocks below, in order. They contain the whole OpenAI section, chat and the loop. This is also where messages: unknown[] becomes history: Message[].

The first block defines what a reply and a protocol are, and two helpers that both protocols use. textOf joins the text parts of a message, and isToolCall narrows a part to a tool call: 

type Reply = { message: Message; finish: "tool-calls" | "stop" | "refusal" }

// A protocol turns the agent's types into one wire format and back.
type Protocol = {
  path: string
  body: (model: string, history: Message[], tools: Tool[]) => unknown
  decode: (json: unknown) => Reply
}

const isToolCall = (part: Part): part is ToolCallPart => part.type === "tool-call"
const textOf = (message: Message) => message.content.flatMap((part) => (part.type === "text" ? [part.text] : [])).join("\n")

Then the OpenAI wire types and the tool wrapper from Part 3, which only moves:

// OpenAI Chat Completions: what Ollama and llama.cpp speak. Only this section knows its wire format.
type OpenAIResponse = {
  choices: { message: { content: string | null; tool_calls?: { id: string; function: { name: string; arguments: string } }[] } }[]
}

const toOpenAITool = (tool: Tool) => ({
  type: "function",

The encoder turns one neutral message into the messages OpenAI expects. A tool message becomes one role: "tool" message per result, with Error: in front of a failure's text. An assistant message becomes content plus tool_calls, with arguments back in string form: 

const toOpenAIMessages = (message: Message): unknown[] => {
  if (message.role === "tool") {
    // One role: "tool" message per result. There is no error flag, so the text carries the failure.
    return message.content.flatMap((part) =>
      part.type === "tool-result"
        ? [{ role: "tool", tool_call_id: part.id, content: part.result.type === "error" ? `Error: ${part.result.value}` : part.result.value }]
        : [],
    )
  }
  if (message.role === "assistant") {
    const calls = message.content.filter(isToolCall).map((call) => ({
      id: call.id,
      type: "function",
      // A string input is raw text that did not parse; send it back as it came.
      function: { name: call.name, arguments: typeof call.input === "string" ? call.input : JSON.stringify(call.input) },
    }))
    return [{ role: "assistant", content: textOf(message) || null, ...(calls.length ? { tool_calls: calls } : {}) }]
  }
  return [{ role: "user", content: textOf(message) }]
}

Last, the protocol itself. decode builds the neutral message from the response and decides finish: 

// Arguments arrive as a JSON string. If it does not parse, keep the raw text as the input.
const parseArguments = (raw: string): unknown => {
  try {
    return JSON.parse(raw)
  } catch {
    return raw
  }
}

const openaiChat: Protocol = {
  path: "/chat/completions",
  body: (model, history, tools) => ({
    model,
    messages: history.flatMap(toOpenAIMessages),
    reasoning_effort: "none",
    tools: tools.map(toOpenAITool),
  }),
  decode: (json) => {
    const message = (json as OpenAIResponse).choices[0]?.message
    if (!message) throw new Error("No choices returned from model")
    const content: Part[] = []
    if (message.content) content.push({ type: "text", text: message.content })
    for (const call of message.tool_calls ?? []) {
      content.push({ type: "tool-call", id: call.id, name: call.function.name, input: parseArguments(call.function.arguments) })
    }
    return { message: { role: "assistant", content }, finish: content.some(isToolCall) ? "tool-calls" : "stop" }
  },
}

chat posts the body and decodes the response. For now it still reads BASE_URL and MODEL from the top of the file: 

const chat = async (history: Message[]): Promise<Reply> => {

    method: "POST",

The loop keeps its shape. It works on history, reads the reply's parts, and collects one tool message per step: 

const history: Message[] = []

while (true) {
  const input = await rl.question("You: ")
  history.push({ role: "user", content: [{ type: "text", text: input }] })

  while (true) {
    const { message, finish } = await chat(history)
    history.push(message)
    for (const part of message.content) {
      if (part.type === "text" && part.text) console.log(`Agent: ${part.text}`)
    }
    if (finish !== "tool-calls") break

    const results: ToolResultPart[] = []
    for (const call of message.content.filter(isToolCall)) {
      console.log(`[tool] ${call.name}(${JSON.stringify(call.input)})`)
      const result = await runTool(call)
      if (result.result.type === "error") console.log(`[error] ${result.result.value}`)
      results.push(result)
    }
    history.push({ role: "tool", content: results })
  }
}

type Route = { protocol: Protocol; baseUrl: string; headers: Record<string, string>; model: string }

  ...selected,

const chat = async (history: Message[]): Promise<Reply> => {
  const response = await fetch(`${route.baseUrl}${route.protocol.path}`, {
    method: "POST",
    headers: { "content-type": "application/json", ...route.headers },

// Reads one string field from model input, or throws a message that says how to fix it.
const field = (input: unknown, key: string, example: string): string => {
  const value = typeof input === "object" && input !== null ? (input as Record<string, unknown>)[key] : undefined
  if (typeof value !== "string") throw new Error(`${key} must be a string, e.g. ${example}`)
  return value
}

const listFiles = async (path: string) => {
  const entries = await readdir(path, { withFileTypes: true })
  return entries.map((entry) => (entry.isDirectory() ? `${entry.name}/` : entry.name)).join("\n")
}

const editFile = async (path: string, oldStr: string, newStr: string) => {
  if (oldStr === newStr) throw new Error("old_str and new_str must be different")

  if (oldStr === "") {
    if (existsSync(path)) throw new Error(`${path} already exists; pass the text to replace as old_str`)
    await mkdir(dirname(path), { recursive: true })
    await writeFile(path, newStr)
    return `Created ${path}`
  }

  const content = await readFile(path, "utf8")
  const matches = content.split(oldStr).length - 1
  if (matches === 0) throw new Error(`old_str was not found in ${path}`)
  if (matches > 1) throw new Error(`old_str matches ${matches} places in ${path}; include more surrounding text`)
  await writeFile(path, content.replace(oldStr, () => newStr))
  return "OK"
}

const saveFile = async (path: string, content: string) => {
  await mkdir(dirname(path), { recursive: true })
  await writeFile(path, content)
  return `Wrote ${content.length} characters to ${path}`
}

const TIMEOUT_MS = 30_000
const MAX_OUTPUT = 10_000

const runBash = (command: string) =>
  new Promise<string>((resolve, reject) => {
    execFile("bash", ["-c", command], { timeout: TIMEOUT_MS, maxBuffer: 10_000_000 }, (error, stdout, stderr) => {
      if (error?.killed) return reject(new Error(`The command ran longer than ${TIMEOUT_MS} ms and was stopped. Try a faster command.`))
      if (error && typeof error.code !== "number") return reject(error)
      const output = `${stdout}${stderr}`
      const shown =
        output.length > MAX_OUTPUT
          ? `${output.slice(0, MAX_OUTPUT)}\n[Output truncated after ${MAX_OUTPUT} characters. Filter it with head, tail or grep.]`
          : output
      resolve(`Exit code: ${error ? error.code : 0}\n${shown}`)
    })
  })

// Never throws: every failure becomes a tool result the model can read.
const runTool = async (call: ToolCallPart): Promise<ToolResultPart> => {
  const done = (result: ToolResultValue): ToolResultPart => ({ type: "tool-result", id: call.id, name: call.name, result })

  try {
    const tool = tools.find((tool) => tool.name === call.name)
    if (!tool) throw new Error(`Unknown tool: ${call.name}. Available tools: ${tools.map((tool) => tool.name).join(", ")}`)

    // A string input is arguments that were not valid JSON; the protocol keeps the raw text.
    if (typeof call.input === "string") throw new Error(`The arguments are not valid JSON: ${call.input}`)

    if (tool.confirm) {

  } catch (error) {

const toOpenAIMessages = (message: Message): unknown[] => {
  if (message.role === "tool") {
    // One role: "tool" message per result. There is no error flag, so the text carries the failure.
    return message.content.flatMap((part) =>
      part.type === "tool-result"
        ? [{ role: "tool", tool_call_id: part.id, content: part.result.type === "error" ? `Error: ${part.result.value}` : part.result.value }]
        : [],
    )

// Anthropic Messages: what Claude speaks.
type AnthropicText = { type: "text"; text: string }
type AnthropicToolUse = { type: "tool_use"; id: string; name: string; input: unknown }
type AnthropicBlock = AnthropicText | AnthropicToolUse | { type: string } // e.g. thinking blocks
type AnthropicResponse = { content: AnthropicBlock[]; stop_reason: string }

const isText = (block: AnthropicBlock): block is AnthropicText => block.type === "text"
const isToolUse = (block: AnthropicBlock): block is AnthropicToolUse => block.type === "tool_use"

// Same name and description as every other tool, but the schema is called input_schema.
const toAnthropicTool = (tool: Tool) => ({ name: tool.name, description: tool.description, input_schema: tool.parameters })

const toAnthropicMessage = (message: Message): unknown => {
  if (message.role === "tool") {
    // All the results of a step go back in one user message, and failures carry is_error.
    return {
      role: "user",
      content: message.content.flatMap((part) =>
        part.type === "tool-result"
          ? [{ type: "tool_result", tool_use_id: part.id, content: part.result.value, is_error: part.result.type === "error" }]
          : [],
      ),
    }
  }
  if (message.role === "assistant") {
    // Send back exactly what the model produced, thinking blocks included, when we kept it.
    if (message.native) return { role: "assistant", content: message.native }
    return {
      role: "assistant",
      content: message.content.flatMap((part): unknown[] =>
        part.type === "text"
          ? [{ type: "text", text: part.text }]
          : part.type === "tool-call"
            ? [{ type: "tool_use", id: part.id, name: part.name, input: part.input }]
            : [],
      ),
    }
  }
  return { role: "user", content: textOf(message) }
}

const anthropicMessages: Protocol = {
  path: "/v1/messages",
  body: (model, history, tools) => ({
    model,
    max_tokens: 16000,
    messages: history.map(toAnthropicMessage),
    tools: tools.map(toAnthropicTool),
  }),
  decode: (json) => {
    const data = json as AnthropicResponse
    const content: Part[] = []
    for (const block of data.content) {
      if (isText(block)) content.push({ type: "text", text: block.text })
      else if (isToolUse(block)) content.push({ type: "tool-call", id: block.id, name: block.name, input: block.input })
    }
    const finish = data.stop_reason === "refusal" ? "refusal" : content.some(isToolCall) ? "tool-calls" : "stop"
    return { message: { role: "assistant", content, native: data.content }, finish }
  },
}

The encoder has three jobs that the OpenAI encoder does differently. It sends every result of a step in one user message and marks failures with is_error, with no Error: prefix. It replays native for assistant messages, which keeps the thinking blocks. And when a message has no native, it rebuilds the blocks from the parts, so a message made from parts alone can still be sent. The decoder fills in native and maps stop_reason: "refusal" to finish.

  const value = typeof input === "object" && input !== null ? (input as Record<string, unknown>)[key] : undefined

const listFiles = async (path: string) => {
  const entries = await readdir(path, { withFileTypes: true })
  return entries.map((entry) => (entry.isDirectory() ? `${entry.name}/` : entry.name)).join("\n")
}

const editFile = async (path: string, oldStr: string, newStr: string) => {
  if (oldStr === newStr) throw new Error("old_str and new_str must be different")

  if (oldStr === "") {
    if (existsSync(path)) throw new Error(`${path} already exists; pass the text to replace as old_str`)
    await mkdir(dirname(path), { recursive: true })
    await writeFile(path, newStr)
    return `Created ${path}`
  }

  const content = await readFile(path, "utf8")
  const matches = content.split(oldStr).length - 1
  if (matches === 0) throw new Error(`old_str was not found in ${path}`)
  if (matches > 1) throw new Error(`old_str matches ${matches} places in ${path}; include more surrounding text`)
  await writeFile(path, content.replace(oldStr, () => newStr))
  return "OK"
}

const saveFile = async (path: string, content: string) => {
  await mkdir(dirname(path), { recursive: true })
  await writeFile(path, content)
  return `Wrote ${content.length} characters to ${path}`
}

const runBash = (command: string) =>
  new Promise<string>((resolve, reject) => {
    execFile("bash", ["-c", command], { timeout: TIMEOUT_MS, maxBuffer: 10_000_000 }, (error, stdout, stderr) => {
      if (error?.killed) return reject(new Error(`The command ran longer than ${TIMEOUT_MS} ms and was stopped. Try a faster command.`))
      if (error && typeof error.code !== "number") return reject(error)
      const output = `${stdout}${stderr}`
      const shown =
        output.length > MAX_OUTPUT
          ? `${output.slice(0, MAX_OUTPUT)}\n[Output truncated after ${MAX_OUTPUT} characters. Filter it with head, tail or grep.]`
          : output
      resolve(`Exit code: ${error ? error.code : 0}\n${shown}`)
    })
  })

    return { message: { role: "assistant", content }, finish: content.some(isToolCall) ? "tool-calls" : "stop" }
  },
}

// Anthropic Messages: what Claude speaks.
type AnthropicText = { type: "text"; text: string }
type AnthropicToolUse = { type: "tool_use"; id: string; name: string; input: unknown }
type AnthropicBlock = AnthropicText | AnthropicToolUse | { type: string } // e.g. thinking blocks
type AnthropicResponse = { content: AnthropicBlock[]; stop_reason: string }

const isText = (block: AnthropicBlock): block is AnthropicText => block.type === "text"
const isToolUse = (block: AnthropicBlock): block is AnthropicToolUse => block.type === "tool_use"

// Same name and description as every other tool, but the schema is called input_schema.
const toAnthropicTool = (tool: Tool) => ({ name: tool.name, description: tool.description, input_schema: tool.parameters })

const toAnthropicMessage = (message: Message): unknown => {
  if (message.role === "tool") {
    // All the results of a step go back in one user message, and failures carry is_error.
    return {
      role: "user",
      content: message.content.flatMap((part) =>
        part.type === "tool-result"
          ? [{ type: "tool_result", tool_use_id: part.id, content: part.result.value, is_error: part.result.type === "error" }]
          : [],
      ),
    }
  }
  if (message.role === "assistant") {
    // Send back exactly what the model produced, thinking blocks included, when we kept it.
    if (message.native) return { role: "assistant", content: message.native }
    return {
      role: "assistant",
      content: message.content.flatMap((part): unknown[] =>
        part.type === "text"
          ? [{ type: "text", text: part.text }]
          : part.type === "tool-call"
            ? [{ type: "tool_use", id: part.id, name: part.name, input: part.input }]
            : [],
      ),
    }
  }
  return { role: "user", content: textOf(message) }
}

const anthropicMessages: Protocol = {
  path: "/v1/messages",
  body: (model, history, tools) => ({
    model,
    max_tokens: 16000,
    messages: history.map(toAnthropicMessage),
    tools: tools.map(toAnthropicTool),
  }),
  decode: (json) => {
    const data = json as AnthropicResponse
    const content: Part[] = []
    for (const block of data.content) {
      if (isText(block)) content.push({ type: "text", text: block.text })
      else if (isToolUse(block)) content.push({ type: "tool-call", id: block.id, name: block.name, input: block.input })
    }
    const finish = data.stop_reason === "refusal" ? "refusal" : content.some(isToolCall) ? "tool-calls" : "stop"
    return { message: { role: "assistant", content, native: data.content }, finish }
  },
}

const chat = async (history: Message[]): Promise<Reply> => {
  const response = await fetch(`${route.baseUrl}${route.protocol.path}`, {
    method: "POST",
    headers: { "content-type": "application/json", ...route.headers },
    body: JSON.stringify(route.protocol.body(route.model, history, tools)),
  })
  if (!response.ok) throw new Error(await response.text())
  return route.protocol.decode(await response.json())
}

while (true) {
